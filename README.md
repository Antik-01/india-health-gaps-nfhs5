# NFHS-5 State Health Dashboard

An interactive Streamlit dashboard for comparing Indian states and Union Territories on **maternal health**, **child vaccination coverage**, and **child nutrition** using data from India's National Family Health Survey (NFHS-5, 2019–21).

---

## Dataset

| Item | Detail |
|---|---|
| **Survey** | National Family Health Survey – 5 (NFHS-5, 2019–21) |
| **Source** | Ministry of Health and Family Welfare, Government of India |
| **Official page** | <https://www.data.gov.in/catalog/national-family-health-survey-nfhs-5-provisional> |
| **Raw file used** | `NFHS_5_Factsheets_Data.xls` — sheet *India & States* (112 rows × 136 columns) |
| **Clean file** | `NFHS5_clean.xlsx` (generated by `build_nfhs5_dataset.py`) |
| **Coverage** | India (national) + 36 States/UTs, each with Total / Urban / Rural breakdowns = **111 data rows** |

## Project Description

NFHS-5 is India's most comprehensive household health survey. This project extracts, cleans, and visualises the factsheet data across three analytical domains:

- **Maternal Health** — antenatal care, tetanus protection, IFA supplementation, institutional deliveries, postnatal care, skilled birth attendance
- **Vaccination** — full immunisation, BCG, polio, pentavalent/DPT, MCV1/MCV2, rotavirus, vitamin A
- **Child Nutrition** — breastfeeding, complementary feeding, stunting, wasting, underweight, anaemia

The dashboard computes **composite performance scores** for every state using three user-selectable methods (min-max, z-score, percentile), groups states into **quartile tiers**, and exposes seven analytical views:

1. **Overview** — national KPI cards, best/worst per domain, composite ranking table  
2. **Map & Rankings** — Plotly tile-grid map of India (no GeoJSON or internet required) + tier-coloured bar chart  
3. **Gap Analysis** — gap to India / best state, score heatmap, inequality spread, care cascades, domain-vs-domain scatter  
4. **Urban vs Rural** — diverging gap chart per indicator using raw area rows only (no imputation)  
5. **Drivers** — Spearman correlation heatmap of context variables vs health scores, scatter with trend line  
6. **State Profile** — radar chart + headline KPI metric cards + weakest-5 indicators for 1–2 selected states  
7. **Data & Method** — data dictionary, suppression notes, scoring explanation, CSV download  

Key data-quality rules respected throughout:
- Suppressed cells (`*`) are stored as `NaN` — never as `0`
- Low-sample estimates (originally stored as negative numbers in Excel) are converted to their absolute value and flagged with `†`
- All findings are computed from the data; nothing is hard-coded

## Setup & Run Instructions

### 1. Prerequisites

- Python 3.9 or later
- `pip` package manager

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the clean dataset (if not already present)

```bash
python build_nfhs5_dataset.py
```

This reads `NFHS_5_Factsheets_Data.xls` and produces `NFHS5_clean.xlsx` and `NFHS5_values.csv` in the same folder.

### 4. Run the dashboard

```bash
# Recommended (works even if 'streamlit' is not on PATH):
python -m streamlit run app.py
```

Open your browser at **http://localhost:8501**.

> **Windows note:** If `streamlit run app.py` gives a "not recognised" error, use `python -m streamlit run app.py` instead.

### 5. Data fallback

The app looks for data in this order:
1. `NFHS5_clean.xlsx` (same folder) — full featured
2. `NFHS5_values.csv` (same folder) — scores work, dictionary unavailable
3. `st.file_uploader` prompt — upload `NFHS5_clean.xlsx` through the browser

## Key Findings (auto-generated by dashboard)

All findings visible in the **Overview** tab are computed live from the data. The dashboard never hard-codes any conclusion — switching area or scoring method immediately updates every chart, card, and text finding.

## Scoring Methodology

Each indicator is scored 0–100 where **higher always means better**:

- **min-max**: `(value − min) / (max − min) × 100`; reversed for lower-is-better indicators
- **z-score**: standardised, then min-max rescaled to 0–100
- **percentile**: percentile rank; reversed for lower-is-better indicators

**Domain score** = unweighted mean of indicator scores (requires ≥75 % of indicators present).  
**Composite score** = mean of the three domain scores (requires all three).  
**Tiers**: Bottom (0–25) · Lower-mid (25–50) · Upper-mid (50–75) · Top (75–100).

> NFHS fact sheets provide no confidence intervals. Small score differences between states are not statistically meaningful. Tiers, not exact ranks, are the appropriate unit of comparison.
